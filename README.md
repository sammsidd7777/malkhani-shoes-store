# Malkhani Shoes - Frontend

A modern and responsive e-commerce shoe store frontend built using React.js. This project provides a smooth shopping experience with product browsing, product details, cart functionality, and a user-friendly interface.

## 🚀 Features

- Responsive modern UI design
- Product listing and product details
- Category-based product browsing
- Shopping cart functionality
- User authentication integration
- API integration with backend
- Fast performance with Vite
- Mobile-friendly design

## 🛠️ Tech Stack

- React.js
- Vite
- JavaScript (ES6+)
- Tailwind CSS
- React Router
- Redux Toolkit / RTK Query
- Axios
- Lucide React Icons
